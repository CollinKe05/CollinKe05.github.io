vscode

task.js是给compiler的

launch.js 是给debugger的

使用g++和gdb进行编译和调试

💡g++是一个linux适用的编译器，也可以说装了msys之后把linux的编译器适配到了windows

1. 启动方式

直接用vscode打开项目文件夹。

2. 生成配置

然后点右上角的小齿轮，选择使用g++.exe第一条

3. 编译

生成完之后直接小齿轮旁边的带虫子的小三角形编译debug运行。

第一次出现选择也照样选g++，第一次编译报错正常，再编译一次就行

使用MSVC的cl.exe进行编译和调试

💡msvc可以理解为g++编译器的windows适应版本

1. 启动方式

要使用cl.exe编译，必须
先在开始菜单搜 Developer Command Prompt for VS 2022，打开黑窗口，输入 code . 启动 VS Code打开的页面进行编译，这样才可以activate cl.exe。

2. 生成配置

法一：

点右上角的小齿轮，选择使用cl.exe第二条

法二：

  • 菜单栏 终端 -> 配置默认生成任务。
  • 必须选： C/C++: cl.exe 生成活动文件。

3. 编译

直接小齿轮旁边的带虫子的小三角形编译debug运行。

第一次出现选择也照样选cl.exe，第一次编译报错正常，再编译一次就行

cmake编译大型项目

💡只需要在 `CMakeLists.txt` 里写一句：“ **把这个文件夹下所有的代码编译成一个叫 Game 的程序** ”。然后，CMake 会自动检测你的电脑是 Windows 还是 Linux，自动帮你生成适合那个系统的“编译命令”。

核心语法

先装了，晚点再学吧！😀

Python

python环境比较多样，有.venv、uv、conda等。

vscode配置conda

1. 选“解释器” (Interpreter)

打开 .py 文件

看 VS Code 右下角 ，通常会显示一个 Python 版本号（比如 3.9.1 64-bit）。

或者，按 Ctrl + Shift + P，输入 Python: Select Interpreter。

在弹出的列表里，你会看到你电脑上所有的 Python。找到那个带有 ('你的环境名': conda) 字样的选项，选中它！

2. 运行

选中后，新建一个终端（Ctrl + Shift + ~），你会发现 VS Code 自动在命令行里帮你敲好了 conda activate xxx，前缀变成了 (你的环境名)。

直接点右上角的 “播放按钮” （选择 Run Python File），或者按 F5 调试。

Pycharm

💡PyCharm 比较重，不要让它创建新环境 (venv)，而是直接“挂载”到我们配好的 Conda 环境上。

新建项目 (New Project)
在创建窗口，找到 Interpreter type (解释器类型)。

  1. 选择环境
    • 选 Custom environment (自定义环境)。
    • 选 Select existing (选择现有)。
    • 类型选 Conda 。
  2. 指定路径 (最关键)
    • Conda Executable: 指向 miniforge3\\Scripts\\conda.exe (通常会自动识别)。
    • Environment: 浏览文件夹，找到你的环境目录：
      C:\\Users\\你的用户名\\miniforge3\\envs\\mcm2026\\python.exe
  3. 完成
    点击 Create，右下角显示 Python 3.11 (mcm2026) 即成功。
